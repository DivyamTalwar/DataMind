\title{DataMind: A Profile-Scoped Multi-Surface Data Plane for Agents}

\begin{abstract}
Tool-using agents increasingly operate over workspaces that combine documents,
tables, graphs, and persistent state. These sources are commonly exposed as
independent tools, leaving construction, revision visibility, provenance,
concurrent maintenance, and failure recovery to application code. We present
\textbf{DataMind}, a profile-scoped multi-surface data plane for agents. A
Build Agent materializes raw workspace artifacts into validated document,
database, graph, and memory surfaces and publishes a profile snapshot. A
Serving Agent selects and composes surfaces for a request, returning evidence
linked to sources and revisions. Shared surface contracts, receipts, snapshot
publication, incremental updates, and bounded recovery connect the two paths.
We evaluate the serving path with the auditable WorkSurface-Bench workload and
the build path with WorkSurface-Build, then measure update visibility,
concurrency, profile isolation, and source-fault recovery. The resulting
build--serve--update--recovery lifecycle positions DataMind as a data
management system for tool-using agents rather than as another vertical RAG
application or collection of agent tools.
\end{abstract}
